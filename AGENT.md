# Работа с Music MVP

Контекст: это медиатека Александра. Имеются личные жанры German Hip-Hop, Russian-German Hip-Hop и French Hip-Hop. Предпочтения пользователя имеют приоритет над общей классификацией каталога. Основной интерфейс — команды, без управления экраном Music.

1. Прочитать README и запрос. Не менять старый французский план и не расширять пилот на всю библиотеку.
2. Для первого запуска выполнить doctor и prepare на examples/french-five.json. Это чтение и загрузка обложек, без записи музыкальных полей.
3. Проверить preview. Поиск кандидатов доступен через search, но автоматически выбирать первый результат нельзя. Сверять артиста, версию, релиз, номера и длительность. Producer не переносить в Composer.
4. Применять конкретный план в рамках авторизованной пользователем задачи. Команда apply сохраняет резервные файлы и журнал. Не модифицировать исходные контрольные значения before, чтобы обходить конфликты.
5. Проверить журнал и inspect. Сохранить пользовательские плейлисты/историю. Если этап не прошёл — сообщить точную ошибку и фактическую степень выполнения. Не выдавать проверку в симуляторе за проверку на Mac.
6. На ошибке записи остановиться. Автоотката нет; сначала изучить журнал и копии. Не удалять треки, не импортировать заново, не воспроизводить частично выполненный план вслепую.

Первый пилот: Kaaris — Goulag, Mandalorian; Leto — Paris c'est magique; SCH — Euro; Ziak — Akimbo. Не включать сомнительные версии One Shot, Facom и короткий 63 в первую проверку. Последующие группы готовятся отдельными JSON-запросами по Persistent ID.
