# Работа с проектом

- Это универсальный движок. Пользовательские ID, жанровые предпочтения, обложки и тексты находятся во внешних пакетах данных.
- Сохранять интерфейс `validate → prepare → preview → apply → status`; только apply пишет музыку.
- Не выбирать релиз и не выдумывать кредиты внутри движка. Источником изменений является запрос пользователя.
- При изменении формата обновить README, обезличенный пример и защитные тесты. Проверять stale plans, резервные копии, частичные отказы и прямое чтение тегов.
- Для тестирования записи использовать изолированные копии. Не объявлять имитацию подтверждением записи в реальной медиатеке.
